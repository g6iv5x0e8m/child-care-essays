# 专科联盟在行动  义诊服务惠群众

> 更新时间：2026-09-11 (UTC+8)

为推动《南宁市妇幼健康行动方案》落地落实，推进专科联盟建设，优化整合优质医疗资源，更好地满足基层群众健康需求，3月11日，南宁市妇幼保健院联合上林县妇幼保健院在上林县举办以“圆梦助孕，关爱女性健康”为主题的健康惠民服务活动。这也是市妇幼2022年百场“我为群众办实事”健康惠民系列活动的基层行第二站。

✓

**联盟座谈，共同讨论求发展**

专科联盟座谈会

在首先进行的专科联盟座谈会上，市妇幼保健院副院长周利锴介绍了此次活动的目的和意义，专科联盟工作开展以来在学科建设、人才培养、医疗技术等方面取得的成绩。同时，分析了当前在学科发展、信息互联互通、科研能力以及专家作用发挥方面存在的不足与差距。

周利锴副院长讲话

蒋益宝院长讲话

上林县妇幼党支部书记、院长蒋益宝对市妇幼专家一行的到来表示热烈欢迎，诚挚感谢市级专家团队对上林县妇幼的帮助和支持，并与市妇幼专家团队就加强特色专科建设和专科联盟建设等工作展开深入探讨，希望继续通过双方精诚协作，助力上林县妇幼向更高、更远发展，造福于当地人民群众。

现场还举行了双方妇幼保健相关专科联盟的签约仪式。

儿童眼保健专科联盟签约现场

✓

**健康义诊，让优质医疗在基层落地生根**

义诊现场

此次义诊活动针对群众需求集中、关注度高的慢性病、常见病等病种。选派的专家团队涵盖了不孕不育、优生优育、妇女肿瘤、乳腺疾病、妇女保健、脊柱•关节疾病难症顽症重症、眼耳鼻咽喉头颈外科等专科。

市妇幼专家为当地群众进行健康义诊

现场，专家们免费为当地群众提供咨询和健康指导，免费为患者检查身体，耐心细致解答群众的各种疑难问题，并对患者带来的检查材料进行详细地分析和提出缜密的治疗方案。很多患者慕名而来，纷纷为市妇幼这一大大方便患者的举措点赞。

中医科专家安平教授为群众检查脊柱

此次义诊活动持续3个多小时，共为100余名患者提供了健康指导和疾病咨询，让上林县百姓真真切切体验到家门口的“三甲”医院服务，真正实现了便民、利民、惠民。

志愿者为现场群众提供咨询帮助

✓

**专科讲座，助力基层加速跑**

讲座现场

在义诊的同时，市妇幼专家分别围绕《不孕症诊治新认识》《试管婴儿你想知道那些事？》《中医诊疗体系在妇幼医院的切入点及中国整脊学、银质针中医核心技术在脊柱•关节疾病难症顽症重症的临床应用》《乳腺疾病三才疗法的临床运用》等内容为上林县医疗集团妇产科、妇保科、中医科医护人员进行精彩授课。

专家授课现场

会议现场气氛活跃，参会人员就妇幼健康相关问题进行了热烈的讨论。专家们也针对各专科的发展和下一步的规划与学员进行了探讨交流。

学员们表示，专家们不仅为他们带来了新知识、新技术，还搭建了上级专家和基层医护人员的沟通平台，有利于基层医疗技术水平的提升，更好地为全县及周边地区人民群众的生命健康保驾护航。

✓

**教学查房，传帮带落到实处**

专家教学查房中

专家团队成员分别深入上林县妇幼病区开展教学查房和病例讨论，专家们结合自己多年的临床经验，从疾病诊断、用药、观察、治疗要点等方面做了详细的汇总分析，并提出了相应的治疗建议，为患者量身定制治疗方案。

专家教学查房中

同时，针对病情进行分析讨论，解决诊疗过程中的疑难困惑，使县妇幼医护人员受益匪浅，丰富了大家专业知识，提升了基层医疗诊疗水平。

下一步，南宁市妇幼将始终秉持“一切为了妇女儿童的健康”宗旨，聚焦群众“急难愁盼”问题，持续派驻优秀的专家定期到基层坐诊开展帮扶活动，不断提升专科联盟基层成员单位的诊疗水平，继续推动专科联盟建设，聚力高质量发展内涵，为广大妇女儿童提供持续便捷、高效、优质、优惠的健康服务，以优异成绩迎接党的二十大胜利召开。
